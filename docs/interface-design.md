# 简迹界面设计规范

## 产品表达

以「个人材料工作室」组织体验。首页解释如何把真实经历整理成适合目标的材料；工作台优先帮助用户找到文档；编辑器提供足够的文字阅读和审阅空间。用途描述覆盖学习、研究、求职、转岗和项目合作，不以用户身份限制入口。

首页示例包含实际排版与来源批注，并明确标注虚构。工作台列表接口只包含摘要，因此缩略图标为「版本封面」，不声称呈现文档全部内容。版式选择使用已有简历预览组件，示例内容不会写入新草稿。

## 视觉基础

- 主色：森林绿 `#216553`；正文：墨绿 `#1c2c27`；页面：暖白 `#fdfdfa`；工作区：`#f3f5f1`。
- 通过字号、间距、分隔线建立层次。阴影只用于纸面、弹窗与浮层，避免给每段文字增加卡片。
- 全站界面只使用 `--font-ui` 定义的中文无衬线字体栈，标题、正文、数字和按钮遵循同一体系。正文 16px，操作 14px，辅助信息 12px；分组标题 20/24px，页面标题 32px，首页首屏标题按屏宽为 32–56px。字重仅使用 400/500/600，不再混用衬线、斜体数字和装饰英文。实际导出文档的模板字体由版式决定。
- 页面容器最大 1240px，桌面两侧至少 32px，手机两侧 18px。标题需检查中文换行，避免结尾仅剩一个字。
- 常规按钮圆角 7px，文档与容器 10–14px。焦点清晰可见，减弱动态效果的系统设置应受到尊重。

## 动效与引导

- 首屏标题与纸张在进入时轻轻落位；下方内容仅在首次滚入时渐显，位移不超过 16px。交互反馈约 180–260ms，段落入场约 520ms，不使用持续漂浮、自动轮播或强制新手弹窗。
- 用途区通过选择、示例与下一步按钮提供引导，不增加重复的步骤条。切换只更新示例与建议，不自动滚动；手机用户主动点击查看后，滚动并聚焦示例标题。创建入口延续已选的学习或职业用途。
- 手机版式支持滑动、前后按钮与方向键，当前位置和边界随滚动、窗口宽度变化更新。桌面可完整并列时隐藏翻页控制。
- 页面顶部细线表示阅读进度，内容导航标出当前章节。减少动态效果设置下取消入场、位移和顺滑滚动；关闭 JavaScript 或缺少滚动观察能力时，正文仍然可见。

## 核心页面

- 导航：营销页左侧是品牌，中间是产品介绍、简历版式和价格说明，右侧按登录状态显示「登录 / 免费开始」或「进入工作台 / 账户」。工作台、账号页和管理页使用工作区页头，只显示位置与账户，不摆放定价或重复的新建按钮。子页面保留返回「我的简历」的路径，登录后返回当前页面。手机产品菜单和登录入口都有文字标签，菜单支持键盘、Escape 与点击外部关闭。
- 首页：双栏首屏、四种用途示例、原始经历到候选表达的三步示例、三套真实版式、四种交付方式、常见问题和叠纸收尾。用途可切换，手机版式可横向浏览，页内导航帮助快速定位。示例与试点功能明确标注，避免把计划能力当作已开放功能。
- 工作台：以「我的简历」、数量和简短说明开头，再呈现用途筛选、搜索及网格/列表切换。主创建按钮只出现一次：有文档时放在内容顶部，无文档时放在空态。访客说明保持简短，登录合并账号作为次要入口。
- 新建：先选用途，再补目标与方向，最后选版式。底部按钮说明当前下一步，并聚焦尚未填写的字段。选定目标后收起目录，可主动更换；重复选择当前用途不清空已填内容。桌面说明与选项分栏，手机顺序排列；长内容在弹窗内滚动，提交按钮保持可达。
- 编辑器：「编辑资料」「成品预览」「材料助手」三个明确视图。宽屏编辑或审阅时保留纸面预览；窄屏一次呈现一个主任务。
- 材料助手：来源、原文、候选、追问、确认分层呈现。宽屏可并排比较，手机顺序阅读。应用修改、撤销和恢复任务继续沿用既有状态与确认逻辑。

## 验收记录

本轮由三个设计与前端子代理并行完成，实现后使用本地 Chromium 截图进行人工视觉检查。主页面覆盖桌面与手机；重点补查 320px 小屏、长标题、已登录账号导航、空/有数据列表、新建长表单、编辑器视图和抽屉。

`scripts/verify-agent-workspace.mjs` 已适配新的视图入口，继续验证追问、来源、确认、撤销、冲突、旧结果、取消、回执丢失恢复和手机审阅等交互。浏览器验收使用虚构数据及接口模拟，不代表真实 Codex 服务端执行验收。

视觉截图与临时检查脚本保存在被忽略的 `.data/` 目录；产品代码、公共样式及回归脚本随仓库版本保存。

首页内容扩充后，补查了 1440、1024、768、390、320px 五档宽度：用途切换、问答展开、页内导航、移动端版式横向浏览与完整纸面展示。截图保存在 `.data/home-expanded-review/`。

动效与引导补查了正常/减少动态效果、一次性入场、关闭 JavaScript、缺少 IntersectionObserver、焦点与用途衔接；版式覆盖 320、390、768、900、1440px 的滑动、按钮、键盘和窗口变化。记录保存在 `.data/home-motion-review/` 与 `.data/template-motion-review/`。

统一排版与导航后，补查首页实际渲染字体、工作区空/有数据、新建步骤、320px 编辑器和登录返回地址。匿名/登录 × 营销/工作区 × 三档宽度共 12 组导航检查通过；创建慢请求与失败时焦点保持在弹窗内，已有会话缓存不会造成初始页面不一致。账户页实际 UI 字体栈为一套、字重为 400/500/600。类型、全量 lint、生产构建和产物检查通过；材料助手原有 10 组浏览器回归通过。截图位于 `.data/home-typography-review/`、`.data/navigation-reset/`、`.data/workspace-logic-review/` 和 `.data/unified-editor-review/`，验收数据均为虚构接口响应。
