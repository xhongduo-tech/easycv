# 简迹 CV

简迹 CV 是一个面向中国学生的目标驱动简历平台。它覆盖两条核心路径：

- 留学申请：根据大学、地区与申请方向组织教育、研究和项目证据。
- 毕业求职：根据国企、大厂与岗位方向突出能力、业务影响和关键词连接。

项目采用 clean-room 方式实现：研究了 Resume.com 的公开信息架构与常见简历产品流程，但未复制其商标、受版权保护的文案、图片、模板、源码或不可见的后端架构。

## 当前可用能力

- 原创品牌首页与双赛道入口
- 186 个目标适配方案：101 所院校、85 家企业，按地区或企业类型二级选择
- 16 套原创共享视觉版式（留学与求职各 8 套），按目标推荐排序
- 目标搜索、自定义目标、场景标签与非官方编辑建议说明
- 服务端简历 CRUD、软删除与用户级资源隔离
- D1/SQLite 持久化、修订快照和审计事件
- 六大简历章节编辑、实时 A4 预览、自动保存
- 确定性规则建议引擎，无外部 AI 密钥也可运行
- 建议接受/保留流程和事实核验提示
- PDF 打印、ATS 纯文本和 JSON 导出
- GitHub Pages 单文件网页简历导出，默认隐藏联系方式并使用严格 CSP/HTML 转义
- 基于当前目标与已有证据的成长路线，以及 13 项官方课程/训练资源
- 个人工作台：搜索、筛选、重命名、复制、归档
- 演示管理台：指标、赛道分布、内容治理和健康检查
- 响应式布局、键盘焦点、减少动态效果与打印样式

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

开发服务器会输出实际本地地址。D1 在本地由 Cloudflare Miniflare 提供，首次 API 请求会自动创建表并写入种子数据。

## 质量检查

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

数据库结构定义保存在 `db/schema.ts`，已生成并审查的初始迁移保存在 `drizzle/`。

## 数据与安全说明

- 当前版本为浏览器级私有访客空间：随机 HttpOnly 会话令牌映射到独立用户，所有简历 API 都在服务端校验资源所有权。
- 清除浏览器数据后访客可能无法再次访问原草稿；生产接入真实用户前仍应启用账号认证、管理员 MFA、限流、隐私同意、数据保留和账号删除流程。
- 规则建议不会调用第三方模型，也不会自动虚构成绩、工作经历或量化成果；CV 正文会发送到本平台 API 进行检查与保存。
- 如果未来启用外部 AI，需要在发送 CV 内容前取得用户明确同意，并完成个人信息保护法/GDPR 专项评估。
- 产品管理员不能获得服务器 Shell 或宿主电脑控制权；产品角色与云端运维 IAM 必须隔离。

## 后续路线图

1. 真实身份认证、访客草稿迁移和多工作区权限。
2. 目标画像 CMS、来源 URL、审核/发布流程与有效期提醒。
3. 上传 PDF/DOCX、字段映射、OCR 与原文件独立删除。
4. 服务端 PDF/DOCX 渲染 Worker 与导出任务队列。
5. AI 供应商适配器、结构化输出、用量预算和审计。
6. 版本差异、目标分叉、导师评论与协作。
7. GitHub OAuth 可选授权与一键建仓；当前版本坚持无账号权限的上传就绪导出。

详细设计见 [架构说明](docs/architecture.md) 与 [API 说明](docs/api.md)。
